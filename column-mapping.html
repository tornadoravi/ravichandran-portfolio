Design rationale / Reading the supplied interfaces

Structure first. Dependencies made visible.

The challenge: source columns alone do not explain how a planning view should interpret dates, effort, people, or costs.

  1. 01

    Separate the layout from the data role.

    Keep Gantt or Resource visible in the layout navigation while tabs divide the mapping domains. This reduces one long form, at the cost of navigation between domains.

  2. 02

    Expose the relationship, not just the field.

    The resource form names both sides of the ID relationship: current table and resource table. More explicit labels take space, but distinguish similar-looking selectors.

  3. 03

    Explain a blocked state where it occurs.

    The Cost banner names resource mapping as a prerequisite for Standard and Usage Cost. Disabled controls alone would not explain the next action.

01 / Gantt · Task

Establish task identity and timing.

Start Date, End Date/Duration, and Task ID define the core mappings. Parent ID and Multiple Column Hierarchy provide alternative ways to represent task structure.

The selected Parent ID state pairs Parent_Id with Task_Name. Milestone and Progress are also visible.

This attachment is lower resolution and is deliberately shown without enlargement. The banner describes shared configuration across layouts; the still image does not verify synchronization.

02 / Gantt · Time Entries

Connect recorded effort to the task.

The screen separates Direct Time Entry from Time entry with Approvals. In the visible direct-entry state, Time Entries is the source table, Task_Id connects it to a task, and Hours_Logged maps actual effort in hours.

Save is enabled in this state. The approvals route is visible as an option, but its configuration is not shown.

03 / Gantt · Resource

Make both sides of the relationship explicit.

Employees is selected as the resource table. Assigned To identifies the resource from the current table; a second selector identifies the matching ID from the resource table.

The related ID and display-column mappings remain incomplete, and Save is disabled. This records the visible state, not a tested validation sequence.

04 / Gantt · Cost

Name the prerequisite before asking for costs.

“Complete the Resource mapping to enable Standard Cost and Usage Cost calculations.” The inline message explains why those two selectors are unavailable.

Fixed Cost is shown separately. The screen does not establish calculation formulas, currency handling, or what happens after resource mapping is completed.

05 / Related view · Resource layout

Keep the configuration language consistent across layouts.

Resource is now selected in the left navigation, while Task remains the active mapping tab. Assigned To, dates, Estimated_hours, and filter columns define this view’s task information.

Additional Mapping Options stays collapsed, keeping the core fields visible. This is a related layout, not a mandatory fifth step in Gantt setup.

Evidence & product context

Documented capability. Supplied design, separately.

Microsoft Learn confirms Gantt layout configuration, necessary date and task-ID fields, and optional hierarchy, milestone, progress, dependency, effort, and filter mappings. The overview places PowerTable within Planning in Fabric.

Scope, delivery & source limitations

My contribution: end-to-end Gantt and resource UX/UI within the PowerTable work, including developer handoff and implementation review. This is not a claim of Microsoft employment, suite-wide ownership, or production-code ownership.

Evidence: five supplied design states, cropped locally to their dialogs without repainting controls or changing values. The selected preview repeats the Time Entries state. The numbered walkthrough is a reading order, not a recorded task sequence or historical design iteration.

Status: the public Gantt guide supports core field mapping. It does not independently verify every Time Entries, Resource, or Cost state shown here, their release status, or their runtime behavior. No usability study, reduced setup time, or customer-impact metric is claimed.

Handling: the original attachments carry an internal-only marking. Dialog crops exclude surrounding workspace data; cropping is not publication clearance. This portfolio remains a local preview. Confirm permission before public use.

Source review: official Microsoft Learn pages reviewed November 10, 2026. The Microsoft Fabric icon identifies the platform and is not an endorsement.
