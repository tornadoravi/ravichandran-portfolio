Product context / New to the platform?

Where Analytics+ fits.

Microsoft Fabric is the broader data and analytics platform. Power BI is its reporting and visualization experience. Inforiver Analytics+ is a custom visual from Lumel that report authors add inside a Power BI report.

  1. 01 / The platform

    Microsoft Fabric

    Brings data and analytics workloads together, including Power BI.

  2. 02 / The report environment

    Microsoft Power BI

    Where people build, publish, and explore interactive reports.

  3. 03 / The custom visual

    Inforiver Analytics+

    Added inside the report for advanced charts, layouts, KPI cards, and storytelling.

This is a product relationship, not a required setup sequence or a claim that every Analytics+ user must adopt additional Fabric workloads. Analytics+ is built by Lumel, not Microsoft. Microsoft's Power BI overview ↗ (opens in a new tab)

01 / Why Inforiver Analytics+

More visual power.
A clearer way to use it.

A chart-rich product still needs a clear path from choosing a view to telling a story.

Analytics+ extends Power BI with visualization, report authoring, and storytelling capabilities. The design challenge is to connect chart choice, report composition, and explanation while keeping deeper controls available.

06 / Reflection

One product experience.
Not five isolated screens.

The design thread is the relationship between the decisions an author makes.

Discovery, configuration, report composition, and explanation need different controls, but they should not feel like unrelated products. Carrying the work through handoff and implementation review helps preserve that intended connection.

The feature stories show concrete interface decisions and the supplied evidence behind them. They do not substitute screen counts, vendor claims, or current public comparisons for measured user outcomes.
