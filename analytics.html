Business case

Make a broad catalogue
usable without expertise.

Help report authors turn an analytical question into an appropriate visual.

Analytics+ offers a wide range of charts inside Power BI. Authors who know chart names and authors who know only their analytical goal need different starting points.

The objective was approachable discovery without removing the direct route for experienced authors.

Design rationale

Pain points & solution highlights.

Confirmed workflow problems, paired with the design responses and supporting feature detail.

  1. 01 / Pain point

    The chart name is not always known.

    A broad catalogue is difficult to enter when the user knows the comparison they need, but not the visualization vocabulary.

    Solution highlightOffer Chart and Function routes into the same selection flow: one starts with a family, the other with an analytical goal.

    See discovery routes →
  2. 02 / Pain point

    Selection is only the first decision.

    Measures, labels, and visual styling still need to form a coherent view after a chart is chosen.

    Solution highlightMake Customize a distinct stage for appearance and visibility, with deeper chart-specific settings left in configuration panels.

    See configuration →
  3. 03 / Pain point

    Different decisions compete for attention.

    Appearance controls and analytical rules have different purposes, even when they affect the same chart.

    Solution highlightSeparate Customize from Advanced, with clear movement between stages and a return to the report canvas.

    See Advanced →
01 / Overview

Enterprise analytics.
A clearer starting point.

Inforiver Analytics+ brings no-code analytics, dashboarding, and reporting into Microsoft Power BI.

My work covered requirements and existing-experience reviews with product managers and stakeholders, followed by user flows, prototypes, interaction and visual design, developer handoff, and implementation checks.

This case follows chart selection and configuration. Explore the separate cases for Storyboard authoring → and Annotations, Comments & Presentation →.

02 / The challenge

Many chart options.
Different starting points.

A person who knows the chart name and a person who knows the question need different routes into the same experience.

Actual-versus-target comparison was one of the workflows behind the design problem: select a chart, configure measures and labels, and match KPI styling. A broad catalogue and inconsistent controls complicated that sequence.

The walkthrough shows a multi-measure column-chart example with measures already mapped in Power BI.

03 / Chart type

Browse by chart.
Filter by intent.

Keep the familiar route direct. Make the guided route specific.

Opened from the Chart Type dropdown, the wizard offers Chart and Function routes. Both lead to chart recommendations, with access to Favorites.

PATH A / CHART

Start with a known family

The supplied Chart view has Bar/Column selected. Named thumbnails make the available chart variants visible before proceeding.

PATH B / FUNCTION

Start with the analytical need

The Function view exposes Data type, Use case, Visualize, and Measure filters. The screenshot shows categorical data and the 2–4 measure option selected.

03.1 / Function filters

Make the question
part of the choice.

The open Use case menu shows Comparison, Part to Whole, Ranking, Distribution, and Time series. The separate Visualize menu shows Lines, Points, and Bar, with Boxes disabled in the supplied state.

Separating analytical purpose from visual form gives authors a route into the catalogue without starting from a chart name.

03.2 / Favorites

A shorter route
back to a familiar chart.

The Favorites tab shows a saved Overlapped column chart, while the Function filters remain visible alongside it. Public product documentation also describes adding go-to chart types to Favorites.

Favorites belongs within chart discovery, not as another mandatory stage. It supports returning to a known choice without changing the three-stage structure.

04 / Customize & Advanced

Shape the display.
Then set the analysis.

Customize brings Theme, Font, Auto color, and category fill controls together with visibility toggles for titles, axes, sliders, and Data Label. Back and Proceed provide a route between stages.

Advanced separates analytic controls from the appearance settings. The supplied view has Reference line enabled and sorting set to Descending by AC. TopN is visible as a tab; its configuration is not shown in these screenshots.

The wizard connects selection, appearance, and analysis while deeper chart-specific settings remain in the wider product’s configuration panels. Detailed bullet bands and layouts are part of that broader scope, not the column-chart screens shown here.

05 / Report view

Back to the canvas.
Keep the context visible.

The report view shows a multi-measure column chart by Weekday, with data labels, annotation markers, and an average reference line. The Analytics+ ribbon remains visible above the chart.
